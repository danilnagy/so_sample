# Coding investigation, round 1

## Outcome

Modem reconstruction remains hardware-validated for the controlled baseline. The three
single-event experiments identify position-related transport divergence, but no verified
payload/state representation or writable pattern field has been recovered.

This round adds `po33 analyze-coding`, bounded recurrence/rank probes, a raw-audio clock
cross-check and a reproducible exploratory script. Hypotheses and their tested limits are
recorded instead of interpreting widespread differences as known state fields.

## Positive structural observation

In the fixed prefix window [100,8000), the smallest exact period is 512 phase labels on
the left and 128 on the right. Both channels first break their whole-stream repetition
at label index 8185 in the empty baseline and all three populated captures. This confirms
repeated prefix structure in these recordings, not the precise first payload bit or a
protocol header length. The known 24-packed-byte event displacement remains distinct
from those framing questions and from the failed exact Step 3 prediction.

## Tested models

The main report is ../experiments/coding-probes-004.json. Source/artifact hashes, thresholds,
phase convention, windows, channel lengths, lane order and all candidate counts are included.
The four sign-coordinate lanes are left high/low followed by right high/low. They are
Boolean coordinates of phase labels, not verified protocol bits.

- Linear recurrence tests begin at symbol 20000. Each uses 512 training coordinates and
  512 independent holdout coordinates. Fits for the individual lanes have degree 255-258,
  rather than the supported bound of 32; no small model passes the holdout. All 24 temporal
  stereo lane orderings are also tested, with no supported small recurrence.
- Decimation tests examine strides 1-32, every offset and each of four lanes: 2112 mappings
  per changed state, 6336 total. No degree <=32 candidate survives training in the sampled
  windows. This does not exclude higher-order, nonlinear, differently interleaved or
  state-dependent coding.
- Binary difference matrices have full rank at widths 24, 48, 96, 192 and 384 for the
  selected left/right/stereo mappings. There is no observed linear block constraint in
  those alignments/windows. This is not a proof that all possible error coding is absent.
- Earlier angular differences, same-coordinate XOR and cross-quadrature adjacent XOR did
  not localize the edit. These failed transforms remain hypotheses, not accepted decoding.

The supplemental report is ../experiments/coding-exploratory-001.json, generated by
scripts/exploratory_coding.py for empty A versus Step 1 B:

- Constant modular word differences and simple multiplicative feedback are tested on the
  right stream in [200000,240000), at widths 1/2/4/8 bytes, both meaningful endiannesses,
  and with/without swapping coordinate pairs. No near-exact model is observed: modal
  differences explain at most 2.02% of words, and the best multiplier at most 1.28% of
  eligible odd-predecessor transitions. These are not tests of every PRNG or cipher.
- Fixed word vocabularies are scanned in [200000,600000), at every offset for widths
  6/8/10/12/16/24. Words of up to 12 bits use essentially the full possible alphabet;
  larger words also have many distinct values. No compact fixed line-code alphabet
  emerges in these three mappings. Dynamic codebooks and other serialization are untested.
- Exact 256-coordinate anchors at bit-coordinate positions 20000/100000/200000 have no
  matches in the changed counterpart, even allowing either whole-stream sign inversion
  or arbitrary bit offsets. No alignment is applied. This rejects a simple relocation
  explanation for those anchors, not all possible variable-length coding.

Random-looking differences do not establish encryption, compression, or any checksum.
No transformation has been selected merely because it makes a comparison look better.

## Clock and demodulation cross-check

The raw-audio probe uses the same measured zero crossings as the existing sign-run
method, but estimates a global quarter-cycle grid from circular phase averages. Nominal
carrier is 7812.5 Hz; 1000-frame local windows track drift. It compares inferred grid
increments with the existing 7800 Hz local rounding, without altering stored symbols.

For Steps 1, 2 and 3, both channels have zero interval disagreements. The empty baseline
has one terminal disagreement per channel, near sample 11159622, not in the event region.
These observations argue against accumulated local clock-count slips explaining the large
event differences. They do not prove the phase interpretation or payload framing correct.

Window sensitivity was checked: a 2000-frame estimate loses coherence late in Step 3
(minimum concentration ~0.508) and yields hundreds of disagreements. At 1000 and 500
frames, coherence improves (minimum ~0.775 and ~0.818-0.831) and those disagreements vanish.
The larger-window report remains coding-probes-003.json, not silently overwritten. Report
004 uses the finer tracker. This highlights an estimator limitation, not device bit errors.
Low concentration and rapid drift must be reviewed rather than treated as data corruption.

## Reproduction

Run from the repo root using the selected Python 3.12 environment. Choose new output names
or explicitly use --force; source/output aliases are refused.

```powershell
.\.venv\Scripts\python.exe -m po33_re analyze-coding experiments/event-002-a/derived/analysis-001/capture.symbols.npz experiments/event-001-b/derived/analysis-001/capture.symbols.npz experiments/event-002-b/derived/analysis-001/capture.symbols.npz experiments/event-003-b/derived/analysis-001/capture.symbols.npz --audio-captures experiments/event-002-a/capture.wav experiments/event-001-b/capture.wav experiments/event-002-b/capture.wav experiments/event-003-b/capture.wav --out coding-new.json
.\.venv\Scripts\python.exe scripts/exploratory_coding.py experiments/event-002-a/derived/analysis-001/capture.symbols.npz experiments/event-001-b/derived/analysis-001/capture.symbols.npz --out exploratory-new.json
```

Audio paths, if supplied, must match each artifact's source hash in baseline/variant order.
Missing audio simply means no clock probe; a supplied mismatched source is an input error.
Recurrence and rank windows have fixed size limits, so short artifacts fail explicitly.
This command produces research JSON, not a decoded binary state image.

112 tests passed, including independent recurrence vectors, a held-out counterexample,
known binary ranks, an injected recurrence positive control, analytical clock carriers,
CLI output safety and all existing real-capture/reconstruction/event checks. Ruff lint
and formatting checks pass. No original capture or accepted/rejected restore file was changed.

## Populated-state repeat control completed

The requested event-004-b-repeat recording now matches event-001-b exactly on both
channels: all 1,970,367 phase labels and counts, zero changes/tails/shifts. The recording
level remains suitable. This closes the repeatability question for this tested populated
state; earlier next-control instructions are now completed. No additional recording is
requested by this result. See ../experiments/event-004-b-repeat/validation.md.

The widespread differences between empty and single-kick states are reproducible in
these controlled captures. This supports investigating deterministic coding/serialization,
while leaving its algorithm and payload framing unverified. It does not establish a
universal absence of nonces, prove encryption, or make the observed 24-byte spacing writable.

## Subsequent framing result

Round 2 found exact late-tail coordinate relationships, including a swap/inversion with
opposite one-symbol coordinate lags. This explains much of the apparent full-stream
divergence without identifying payload fields. See framing-investigation.md and
../experiments/framing-probes-002.json. The earlier negative coding probes apply to their
raw-coordinate mappings; they should not be used to rule out coding after a verified
phase interpretation.

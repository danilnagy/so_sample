## Next: copy stored content rather than record again

The user earlier asked about Sound1 versus8. The next controlled comparison now uses1
as an empty destination while retaining the verified source8. Copying preserves the
stored sound input without another uncontrolled ADC recording, making exact content
reuse or slot-dependent representation testable.

Device procedure is the [official copy-sound operation](https://teenage.engineering/guides/po-33/en):
select Sound8, hold write+sound and press1, then return to Sound8. Retain empty Pattern1,
write mode off, playback stopped and unchanged controls. Record one full backup at
../experiments/empty-001-c-copy-to-1/capture.wav. No fresh A/A-return or resampling is
requested. Leave both copies present afterward.

Whether copying shares sample allocation, duplicates transmitted data or affects
metadata/validation is unknown. The experiment measures length and exact reusable
subsequences without predicting a size or applying alignment to rescue a result.
Neither duplicated blocks nor transfer size alone will establish editable sample fields.

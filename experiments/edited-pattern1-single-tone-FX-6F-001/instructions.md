# Single-tone effect order, leg B (footer byte 6F)

Run leg B after leg A has passed:

```powershell
.\.venv\Scripts\python.exe -m po33_re hw run experiments/edited-pattern1-single-tone-FX-6F-001
```

Follow the prompts: restore with only the computer-to-PO-33 cable connected, swap
cables, send the backup, then press Enter and PLAY about one second later for the
14-second playback. Do not press FX, enable write, or move knobs or volumes.
Leg A uses the same steps.

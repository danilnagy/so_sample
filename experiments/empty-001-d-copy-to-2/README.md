and press **2** to copy into empty Sound2, then release. Reselect Sound8, retain empty
Pattern1, write mode off and playback stopped, with other controls unchanged. The
[official guide](https://teenage.engineering/guides/po-33/en) documents this copy operation.

Record one full stereo backup here as **capture.wav** at the current recording settings.
Leave all three slots1/2/8 populated afterward. No new analogue sampling, fresh A or
return recording is requested for this control. Report any unexpected behavior.
